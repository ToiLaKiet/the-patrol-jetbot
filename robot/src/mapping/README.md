# Mapping

[teach.py](teach.py) và [topomap.py](topomap.py) hiện là file trống.
Chưa có code tạo hoặc đọc bản đồ topo trong thư mục này.

Phần ghi hành trình đã triển khai nằm ở [teach/recorder.py](../teach/recorder.py),
không phải `mapping/teach.py`. Nó tạo ảnh và CSV để làm dữ liệu đầu vào;
chưa tự chọn keyframe, tạo graph hoặc tính descriptor PlaceNav.
